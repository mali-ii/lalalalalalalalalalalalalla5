## Истории и критерии приёмки

### US-1. Товары с низким остатком
**Как** менеджер магазина, **я хочу** видеть товары с малым остатком, **чтобы** вовремя пополнять запасы.
**Критерии приёмки:**
- Суммируется количество товара на всех складах.
- Возвращаются товары с общим количеством не более 3.
- Результат отсортирован по возрастанию остатка.
- Для пустого результата интерфейс может показать сообщение «Нет товаров с низким остатком».
**Оценка:** 3 story points  
**Приоритет:** Высокий

### US-2. Поиск товара
**Как** менеджер магазина, **я хочу** искать товар по названию и бренду, **чтобы** быстро находить нужную позицию.
**Критерии приёмки:**
- Поиск не зависит от регистра.
- Проверяются название и бренд.
- Пустой запрос возвращает пустой список.
**Оценка:** 3 story points  
**Приоритет:** Высокий

### US-3. Фильтрация каталога
**Как** менеджер магазина, **я хочу** фильтровать товары по категории и цене, **чтобы** анализировать нужную часть каталога.
**Критерии приёмки:**
- Можно задать категорию, минимальную и максимальную цену.
- Фильтры можно комбинировать.
- Границы цены включаются в результат.
**Оценка:** 5 story points  
**Приоритет:** Высокий

### US-4. Сохранение заказа
**Как** менеджер магазина, **я хочу** сохранять заказ в JSON, **чтобы** сохранить состав заказа между запусками программы.
**Критерии приёмки:**
- Заказы записываются в корректный JSON-файл в UTF-8.
- Существующий файл перезаписывается актуальным списком заказов.
- Путь к файлу можно передать параметром.
**Оценка:** 5 story points  
**Приоритет:** Высокий

### US-5. Аналитика по категориям
**Как** менеджер магазина, **я хочу** видеть число товаров в каждой категории, **чтобы** оценивать ассортимент.
**Критерии приёмки:**
- Возвращается словарь «категория: количество».
- Каждый товар учитывается один раз.
- Для пустого каталога возвращается пустой словарь.
**Оценка:** 3 story points  
**Приоритет:** Средний

### US-6. Просмотр журнала действий
**Как** менеджер магазина, **я хочу** просматривать журнал операций, **чтобы** понимать, какие действия выполнялись.
**Критерии приёмки:**
- Запись содержит время, тип действия и описание.
- Записи отображаются в хронологическом порядке.
- При отсутствии записей показывается пустой список.
**Оценка:** 2 story points  
**Приоритет:** Средний

### US-7. Сортировка каталога
**Как** менеджер магазина, **я хочу** сортировать каталог по названию или цене, **чтобы** удобнее сравнивать товары.
**Критерии приёмки:**
- Поддерживаются сортировки по названию и цене.
- Можно выбрать направление сортировки.
- Исходный список не изменяется.
**Оценка:** 2 story points  
**Приоритет:** Средний

### US-8. Просмотр карточки товара
**Как** менеджер магазина, **я хочу** открывать карточку товара, **чтобы** видеть его основные характеристики.
**Критерии приёмки:**
- В карточке отображаются название, бренд, категория и цена.
- Неизвестный идентификатор обрабатывается понятным сообщением.
- Цена отображается в числовом формате.
**Оценка:** 2 story points  
**Приоритет:** Низкий

### US-9. Проверка доступности товара
**Как** менеджер магазина, **я хочу** видеть, доступен ли товар к продаже, **чтобы** не оформлять заказ на отсутствующую позицию.
**Критерии приёмки:**
- Доступность определяется по суммарному остатку.
- Нулевой остаток означает, что товара нет в наличии.
- Проверка возвращает однозначное логическое значение.
**Оценка:** 3 story points  
**Приоритет:** Низкий

### US-10. Экспорт каталога в CSV
**Как** менеджер магазина, **я хочу** экспортировать каталог в CSV, **чтобы** передать данные для анализа.
**Критерии приёмки:**
- Файл содержит заголовки и строки товаров.
- Файл открывается с корректной кодировкой UTF-8.
- Путь к файлу задаётся параметром.
**Оценка:** 5 story points  
**Приоритет:** Низкий

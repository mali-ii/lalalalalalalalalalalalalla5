# Отчёт о тестировании

## Результат

- Написано тестов: **20**.
- Успешно пройдено: **20**.
- Неуспешно: **0**.
- Покрыты: `get_low_stock`, `search_advanced`, `total_sum`, `add_to_cart`, `remove_from_cart`, `update_quantity`, `cart_total`, а также ожидаемый `ZeroDivisionError`.

## Ошибки, найденные и исправленные

1. `get_low_stock` не суммировал остатки из словаря `sizes`; добавлена поддержка этого формата.
2. В исходном наборе проекта не было `cart_total`; функция добавлена с учётом количества каждой позиции и проверена на нескольких товарах.
3. Реализованы отсутствовавшие в проекте функции `add_to_cart`, `remove_from_cart`, `update_quantity`, чтобы проверить сценарии задания. Добавление несуществующего размера возвращает `False` с сообщением о размере.

## Функции без тестов

`count_by_category` и `save_orders` не покрыты этим набором: занятие сосредоточено на функциях каталога, которые перечислены в требованиях, и на корзине. Их можно добавить в отдельный набор тестов при расширении покрытия.

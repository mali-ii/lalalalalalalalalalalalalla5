# Отладка `get_low_stock`

## Точка останова

В VS Code откройте `shop.py` и поставьте breakpoint на строку `return sorted(...)` внутри `get_low_stock` (строка 24). Запустите Python File через F5, затем используйте Step Into (F11), чтобы зайти в `_total_stock`, и Step Over (F10), чтобы вернуться к сортировке.

## Данные и наблюдения

Для проверки использован список:

```python
products = [
    {"name": "A", "sizes": {40: 1}},
    {"name": "B", "sizes": {40: 10}},
]
limit = 3
```

На строке возврата ожидаемые значения: `limit == 3`, `matches == [{"name": "A", "sizes": {40: 1}}]`; сортировка возвращает товар A. При заходе в `_total_stock` для A переменная `product` содержит словарь с `sizes`, суммарный остаток равен 1.

## Найденная и исправленная ошибка

В исходном варианте `_total_stock` не обрабатывал поле `sizes`, использованное в задании. Для таких товаров функция считала остаток нулевым, поэтому товар B с остатком 10 ошибочно попадал в список низкого запаса. Добавлена сумма значений `sizes`; тесты подтверждают корректную фильтрацию и сортировку.
